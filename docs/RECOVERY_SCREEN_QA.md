# 오류·404 복귀 화면 점검

## 확인한 문제와 수정

- 검은 배경의 공통 오류 화면에서 ‘홈으로’ 링크도 검은 글자·테두리를 사용했다. 밝은/어두운 화면의 버튼·링크·키보드 윤곽선을 한 가지 `dark` 옵션으로 함께 선택한다. Works/Crew의 밝은 화면은 유지한다.
- 관리자 오류 화면만 `reset`을 사용하고 있었다. 설치된 Next.js 16.4.3 문서의 `retry`로 연결해 재조회와 재렌더링을 요청한다. 저장 요청을 다시 제출하는 기능이 아니며, 관리 허브 링크의 기존 미저장/처리 중 이동 보호는 그대로 둔다.
- 404에서는 장식용 큰 숫자가 유일한 h1이고 실제 안내가 문단이었다. 기존 크기·색·간격은 유지한 채 ‘Page Not Found’를 h1·본문 바로가기 대상으로 두고 큰 숫자는 장식으로 처리한다.
- 오류 화면이 같은 주소의 본문을 대체하면 경로 변경 감시만으로는 제목에 초점을 연결할 수 없었다. 공통 오류 제목은 마운트 시 초점이 body로 돌아간 경우에만 기존 포커스 도우미를 사용한다. 남아 있는 입력·링크의 초점이나 inert/hidden/aria-hidden 대상은 건드리지 않는다.
- 루트 레이아웃을 대체하는 `global-error`에도 자체 문서 제목, noindex/nofollow, main 랜드마크와 초점 가능한 제목을 추가했다. 인라인 스타일과 일반 홈 링크를 유지해 공통 스타일·라우터 레이아웃에 의존하지 않는다.

## 404의 실제 주소 처리

- 실제 로컬 브라우저에서 정적 404의 경로 훅이 방문 URL 대신 내부 `/_not-found`를 나타낼 수 있음을 확인했다.
- 이 내부 경로나 준비되지 않은 경로는 `data-page-path`로 출력하지 않는다. 정적 서버가 방문 URL을 추측하거나 경로를 알아내려고 서버 페이지를 동적으로 바꾸지 않는다. 이 경우 기존 제목/해시 바로가기를 사용한다.
- 유효한 경로를 받는 오류·404 클라이언트 화면에서는 그 경로 표식을 사용하므로, 같은 제목 DOM을 재사용하는 탐색도 기존 포커스 제어기와 연결된다. 정적 404에서 경로 훅 자체가 바뀌지 않는 모든 탐색을 별도로 추적하는 라우터 패치를 만들지는 않았다.
- 404 첫 진입에는 자동 초점을 추가하지 않는다. 뒤로/앞으로 복원, 사용자가 선택한 입력의 초점 보존 정책도 유지한다.

## 검증

- 설치된 Next의 `error.md`·`not-found.md`를 확인했다. `retry`는 재조회+재렌더링, `reset`은 재조회 없는 초기화이며, `global-error`는 루트 문서·스타일을 직접 제공해야 한다.
- 회귀 테스트 24개를 추가했다. 공통/관리자 재시도 콜백, 오류 원문 비노출, 어두운/밝은 화면 대비 클래스, 독립 오류 문서 구조, 실제 404 h1, 정적 404 내부 경로 생략, 같은 주소 오류 전환·초점 보존·숨김 대상 제외를 확인한다.
- 404의 제목/홈 링크/noindex/상태 코드가 빠지면 반복 스모크 검사가 실패하도록 추가했으며, 모의 응답으로 각 누락을 검증한다.
- 전체 **5,096개 / 121개 파일**, 타입 검사·ESLint·프로덕션 빌드 통과. 최종 빌드의 로컬 스모크는 **42/42 통과**했다. 404의 실제 HTTP 상태·noindex·안내 제목·홈 링크도 확인한다.
- 실제 로컬 브라우저에서 Tab → 본문 바로가기 Enter → h1 초점 → Tab → 홈 복귀 Enter 순서로 정상 홈 진입을 확인했다. 정적 404에는 내부 경로 표식이 없고, 최종 홈 화면의 본문 초점 연결도 확인했다. 임시 탭·서버는 정리했다.

## 범위와 한계

- 오류 원문은 안내 화면에 출력하지 않으며 기존 개발자 콘솔 기록 정책은 바꾸지 않는다.
- 관리자/공개 서버를 일부러 고장 내는 진단 라우트나 운영 데이터 변경은 추가하지 않았다. 실제 서버 장애에서 `retry` 후 데이터가 복구되는 전체 흐름은 운영 검증 완료로 표현하지 않는다.
- 색 대비 클래스와 DOM/키보드 연결 검사이며 모든 운영체제·스크린리더의 음성 낭독을 직접 평가한 결과는 아니다.
- 운영 데이터·업로드·환경변수·의존성·스키마·커밋·배포는 변경하지 않았다.
