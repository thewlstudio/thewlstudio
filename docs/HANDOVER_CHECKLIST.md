# 인수·인계 체크리스트

설치([가이드](INSTALL_GUIDE.md)) 후, 고객에게 넘기기 전에 설치자가 확인한다. 항목마다 날짜·확인자를 적어 보관한다.

## A. 자동 점검 (약 1분)
- [ ] `npm run provision -- check --env-file <운영 값 파일>` — 오류 0건
- [ ] `npm run smoke https://<고객 사이트>` — 전부 통과
- [ ] 코드 사본에서 `npm run lint && npm run typecheck && npm test` 통과
- [ ] GitHub Actions(CI) 성공

## B. 공개 사이트 (약 5분, 브라우저)
- [ ] 홈·Class·Works·Crew·Studio·Contact가 열리고 **옛 고객 이름·전화·주소·사진이 없다**
- [ ] 페이지 제목·공유 미리보기·사이트맵 주소가 고객 주소로 나온다 (`/sitemap.xml`, 페이지 소스의 `og:url`)
- [ ] 전화·지도·SNS 링크가 고객 것으로 열린다
- [ ] 모바일 폭에서 가로 넘침이 없다

## C. 관리 화면 수동 점검 (약 5분)
고객 소유자 비밀번호로 `/manage`에 로그인해서 한다. 시험으로 만든 항목은 끝나면 삭제한다.
- [ ] 로그인 / 로그아웃, 비로그인 상태에서 `/manage`가 로그인으로 이동
- [ ] 강사 또는 Crew 하나를 열어 **사진은 바꾸지 않고** 글자만 고쳐 저장 → 오류 없이 저장되고 홈페이지에 반영
- [ ] 새 항목을 **비공개**로 만들어 저장 → 홈페이지에는 안 나오고, "홈페이지에서 미리보기"로 보인다(화면 아래 "미리보기 중" 띠) → "미리보기 끝내기" → **공개**로 바꿔 저장하면 홈페이지에 나온다
- [ ] 삭제 → 화면 아래 "되돌리기"로 복원 / 휴지통에서 복원
- [ ] 변경 이력에서 이전 내용으로 되돌리기
- [ ] Contact·Studio 안내 저장 → 홈페이지 반영
- [ ] 첫 화면 안내(투어)와 "처음 설정" 체크리스트가 보인다

## D. 보안·운영
- [ ] `MANAGE_PASSWORD`를 **고객 소유자에게만** 안전한 경로로 전달했고, 설치자의 기록(채팅·메모)에서 지웠다
- [ ] 로컬 `.env.local`에 쓰기 토큰이 없다
- [ ] Sanity 데이터셋이 공개이므로 데이터셋에 비밀번호·개인정보가 없다
- [ ] Sanity 프로젝트·Vercel 프로젝트·GitHub 저장소의 **소유자(Owner)가 고객**이고, 설치자는 필요한 만큼만 멤버로 남았다
- [ ] 백업 1회 실행해 보관 위치를 정했다 (`npx sanity dataset export production backups/…`, MANAGE_GUIDE "백업과 복구")

## E. 고객에게 전달
- [ ] 관리 주소(`https://<고객 사이트>/manage`)와 사용 안내(`/manage/help`), 이 사이트의 `MANAGE_GUIDE.md`의 "운영자" 절
- [ ] 하면 안 되는 것: 비밀번호 공유·메모 방치, 삭제 대신 비공개를 써야 하는 경우, 큰 변경 전 문의
- [ ] 문제가 생겼을 때 연락처, 지원 범위(포함/미포함)
- [ ] 알려진 한계: 저장하면 바로 공개(비공개 상태로 먼저 확인 가능), 공유 비밀번호 1개, 모든 변경이 한 사용자로 기록
